# SROsignal

SROsignal is a Python package for identifying and quantifying short-range order (SRO) motifs in atomic-resolution HAADF-STEM images. It recognizes characteristic polygonal arrangements of atomic columns to classify and count projected SRO motifs in face-centered cubic (fcc) alloys. See [test.ipynb](test.ipynb) for an example workflow.
